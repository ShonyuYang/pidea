## 前言

你有沒有想過，桌上的小裝置不只是冷冰冰的數字儀表板，而是一隻「活著的」像素寵物——牠會在你精神飽滿時開心蹦跳，在你久坐疲憊時無精打采地趴下，用最直覺的方式提醒你：「該休息了」？Reddit 上 r/embedded 社群的開發者 u/Brilliant-Arm-7984 就做出了這樣一台裝置，而且核心感測技術不是手環、不是攝影機，而是 **毫米波雷達**。

## 專案概述

這是一台手持式嵌入式遊戲機，內建 60GHz 毫米波雷達感測器，能夠**非接觸式**偵測使用者的心率與呼吸頻率。裝置中住著一隻像素寵物，牠的狀態會根據你的即時生理數據動態變化：

- 🟢 **精力充沛**：剛開始工作時，寵物開心蹦跳，充滿活力
- 🟡 **略感疲倦**：久坐一段時間後，寵物開始打哈欠
- 🟠 **明顯疲勞**：心率趨勢變化加上長時間靜坐，寵物眼皮下垂
- 🔴 **極度疲憊**：寵物直接趴下，強烈提醒你該站起來走走

開發者表示，目前已設計了 **4～5 種不同的動畫狀態**，每種狀態由心率趨勢與久坐時長的組合觸發，並正在實驗為每個狀態加入對應的音效。

> *「我想要的不是一個儀表板，而是一個讓你真正在意自己疲勞程度的東西。」* — u/Brilliant-Arm-7984

## 技術亮點

### 🎯 毫米波雷達非接觸心率偵測

專案使用的是 **Seeed Studio MR60BHA2** 模組——一款專為心跳與呼吸偵測設計的 60GHz 毫米波感測器。它透過偵測胸腔因心跳產生的微小位移來計算心率，透過 UART 輸出數據，與 MCU 整合相當直覺。

根據開發者的測試，在使用者相對靜止（如坐在辦公桌前）的情境下，心率偵測精度可達 **±2～3 bpm**，與標準脈搏血氧儀相當接近。大幅度身體移動時會產生雜訊，但對於久坐監測的使用場景已經足夠可靠。

### 🧠 疲勞演算法

疲勞程度的判定並非單純依賴心率數值，而是綜合考量：

- **心率趨勢變化**：長時間的心率模式分析
- **久坐時間累積**：持續靜坐不動的時長
- **綜合評分**：兩者加權後映射到寵物的動畫狀態

### 🎮 硬體架構

| 元件 | 規格 |
|------|------|
| **主控 MCU** | ESP32-S3 |
| **雷達模組** | Seeed Studio MR60BHA2（60GHz mmWave） |
| **顯示螢幕** | 1.69 吋 240×280 LCD（ST7789 驅動） |
| **電池** | 1000mAh LiPo |
| **續航力** | 約 4～5 小時（雷達與螢幕持續運作） |

ESP32-S3 提供了足夠的運算能力來同時處理遊戲邏輯、像素動畫渲染，以及與雷達模組的 UART 通訊。開發者也正在開發**低功耗睡眠模式**——當偵測不到人體存在時自動進入省電狀態，以延長續航時間。

### 🎨 像素寵物設計

這個專案最迷人的地方，在於它把枯燥的健康數據轉化為**情感連結**。社群成員紛紛將它比作「真正有用的電子雞（Tamagotchi）」。不同於傳統健康監測裝置只顯示數字，這隻像素寵物讓你對自己的身體狀態產生直覺的共感——看到寵物趴下，你會自然而然想站起來走走。

## 心得與延伸

### 為什麼這個專案值得關注？

1. **非接觸式感測的實用化**：毫米波雷達在消費電子領域的應用正在快速擴展，這個專案展示了一個極具創意的落地場景
2. **情感化設計**：將生理數據轉譯為虛擬寵物的情緒狀態，大幅降低了健康監測的心理門檻
3. **完整的嵌入式實踐**：從感測器整合、訊號處理、遊戲邏輯到硬體設計，涵蓋了嵌入式開發的完整鏈路
4. **開源潛力**：開發者表示正在整理程式碼，計畫開源韌體與硬體設計，未來可能衍生出更多客製化寵物角色或額外健康指標

### 可能的延伸方向

- 🔗 加入藍牙連線，將長期數據同步到手機 App
- 🌙 結合呼吸頻率數據，增加睡眠品質評估功能
- 🏃 多人模式：讓不同使用者的寵物互動，增加社交動機
- 📊 長期疲勞趨勢分析與個人化閾值調整
