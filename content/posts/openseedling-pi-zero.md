## 前言

育苗是園藝最關鍵也最容易翻車的階段——澆太多爛根、澆太少乾死、光照不足徒長、溫度不對不發芽。傳統做法是每天巡視三次、憑手感判斷濕度，但只要出差兩天，一整盤苗就可能全軍覆沒。

**OpenSeedling** 是一個基於 Raspberry Pi Zero 2W 的開源育苗站專案，把「看天吃飯」的育苗流程變成可量化、可自動化的系統。作者之前已經做過 Pi-based 的 GPS 追蹤專案，這次把同樣的 maker 精神帶進了園藝領域。

## 專案概述

### 系統架構

OpenSeedling 以 Pi Zero 2W 為核心控制器，搭配多種感測器和執行器，組成一個完整的閉環控制系統：

| 模組 | 元件 | 功能 |
|------|------|------|
| 控制核心 | Raspberry Pi Zero 2W | 主控制器、WiFi 連線、資料記錄 |
| 土壤監測 | 電容式土壤濕度感測器 | 即時偵測土壤含水量（需搭配 ADC） |
| 環境監測 | DHT22 / BME280 | 溫濕度監控 |
| 自動澆水 | 蠕動幫浦 + 繼電器模組 | 依濕度閾值自動供水 |
| 補光系統 | LED 植物燈 + 繼電器 | 依日照排程開關，模擬最佳光週期 |
| 影像記錄 | Pi Camera Module | 定時拍照做縮時攝影 |

### 運作邏輯

```
感測器讀值 → 判斷閾值 → 觸發動作 → 記錄日誌
    │                                    │
    └──── 每 N 分鐘循環 ────────────────┘
```

1. **土壤濕度低於設定值** → 啟動蠕動幫浦澆水，達到目標值後停止
2. **光照排程到達** → 開啟 LED 補光燈，模擬 14-16 小時光週期
3. **定時拍照** → 每隔固定時間拍攝一張，後期合成縮時影片
4. **資料上傳** → 透過 WiFi 將感測數據推送到儀表板或通知系統

### 為什麼選 Pi Zero 2W？

- **體積小**：整個控制板只有口香糖大小，不佔育苗架空間
- **功耗低**：待機約 0.4W，24/7 運行一個月電費不到 10 元
- **WiFi 內建**：不需額外網路模組，直接連家用 WiFi
- **完整 Linux**：可以跑 Python、cron job、甚至小型 Web 伺服器
- **價格親民**：Pi Zero 2W 約 NT$500，整套系統控制在 NT$1,500 以內

## 技術亮點

### 1. 電容式 vs. 電阻式土壤感測器

這個專案使用**電容式**土壤濕度感測器而非便宜的電阻式。差別在於：

- **電阻式**：兩根金屬探針直接接觸土壤，幾週內就會因電解腐蝕而失準
- **電容式**：探針有絕緣塗層，透過介電常數變化感測濕度，壽命長得多

但 Pi Zero 沒有 ADC（類比數位轉換器），所以需要外接 ADS1115 或 MCP3008 來讀取類比訊號。這是很多新手會忽略的坑。

### 2. 蠕動幫浦的精準控制

育苗最怕的就是澆水過量。蠕動幫浦（peristaltic pump）的優勢在於：

- **流量可控**：轉速決定流量，搭配 PWM 可以精確控制每次出水量
- **自吸能力**：不需要灌引水，水箱放在任意位置都能抽水
- **衛生**：液體只接觸管路，不接觸幫浦機構，管路可更換

一般 12V 蠕動幫浦流量約 100ml/min，對育苗盤來說每次運轉 5-10 秒就足夠。

### 3. 光週期排程

不同植物的育苗期需要不同光週期：

| 植物類型 | 建議光照時數 | 光照強度 |
|----------|------------|----------|
| 番茄、辣椒 | 14-16 小時 | 中高 |
| 生菜、香草 | 12-14 小時 | 中 |
| 多肉植物 | 10-12 小時 | 低中 |

用 Pi 的 cron job 或 Python scheduler 就能精確控制開關時間，比機械定時器靈活得多——還能根據季節自動調整。

### 4. 縮時攝影記錄生長

Pi Camera 定時拍照不只是為了好玩，它有實際的診斷價值：

- **徒長判斷**：如果苗莖在縮時影片中明顯拉長，代表光照不足
- **病害早期發現**：葉片顏色變化在每日觀察中不明顯，但縮時影片中一目了然
- **澆水效果驗證**：可以觀察澆水後土壤表面的變化速度

用 `ffmpeg` 一行指令就能把照片序列合成影片：

```bash
ffmpeg -framerate 24 -pattern_type glob -i '*.jpg' -c:v libx264 timelapse.mp4
```

## 心得與延伸

### 與之前介紹過的 Arduino 灌溉系統比較

我們之前介紹過 [Arduino 自動灌溉系統](/posts/arduino-plant-irrigation/)，兩者的定位不同：

| 面向 | Arduino 灌溉系統 | OpenSeedling |
|------|-----------------|-------------|
| 核心 | Arduino Uno/Nano | Pi Zero 2W |
| 適用場景 | 戶外花園、盆栽 | 室內育苗架 |
| 連網能力 | 需額外模組 | WiFi 內建 |
| 攝影功能 | 無 | Pi Camera 縮時 |
| 補光控制 | 無 | LED 排程 |
| 成本 | ~NT$500 | ~NT$1,500 |
| 程式語言 | C/C++ | Python |

簡單說：Arduino 方案適合「只要自動澆水」的場景，OpenSeedling 適合「想要完整監控育苗全過程」的進階玩家。

### 可能的延伸方向

1. **加入 LoRa 模組**：如果育苗架在溫室或陽台，WiFi 訊號不好，可以用 LoRa 把數據傳回室內
2. **多區域控制**：一台 Pi Zero 2W 搭配多路繼電器，可以同時管理 4-8 個育苗盤，每盤獨立設定
3. **AI 生長預測**：累積足夠的感測數據後，可以訓練簡單的模型預測發芽時間、最佳移植時機
4. **Grafana 儀表板**：把數據存到 InfluxDB，用 Grafana 做漂亮的歷史趨勢圖
5. **Home Assistant 整合**：透過 MQTT 接入智慧家庭系統，手機隨時查看苗況

### 給新手的建議

如果你是第一次做自動育苗系統，建議從最小可行方案開始：

1. **第一步**：Pi Zero 2W + 電容式土壤感測器 + ADS1115 → 先做到「能讀到濕度數值」
2. **第二步**：加蠕動幫浦 + 繼電器 → 實現自動澆水
3. **第三步**：加 LED 燈 + 排程 → 補光控制
4. **第四步**：加 Pi Camera → 縮時攝影

每一步都先穩定運行一週再加下一步，避免一次搞太多東西出問題時找不到原因。
