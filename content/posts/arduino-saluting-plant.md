## 前言

養植物最大的成就感是什麼？看到它長新葉？開花？Reddit 用戶 u/DaGermanBear 給了一個更即時的答案：**讓植物在你澆完水後，立刻向你敬禮致謝。**

這個專案用 Arduino 搭配土壤濕度感測器和伺服馬達，做出一個會「回應」你的花盆。土壤夠濕 → 植物開心 → 機械手臂舉起敬禮。簡單、無厘頭、但莫名療癒。

## 專案概述

### 核心架構

整個系統只需要三個主要元件：

| 元件 | 功能 | 預估價格 |
|------|------|----------|
| Arduino Uno / Nano | 主控制器 | ~NT$150–350 |
| 電容式土壤濕度感測器 | 偵測土壤含水量 | ~NT$30–60 |
| SG90 伺服馬達 | 驅動敬禮手臂 | ~NT$30–50 |

**總材料費約 NT$250–500**，是極低門檻的入門專案。

### 運作原理

1. **感測階段**：電容式土壤濕度感測器持續讀取土壤介電常數，轉換為類比數值（0–1023）
2. **判斷階段**：Arduino 將讀數與預設閾值比較，判定「乾燥」或「濕潤」
3. **動作階段**：當土壤從乾燥轉為濕潤（剛被澆水），伺服馬達驅動機械手臂做出敬禮動作
4. **復位階段**：手臂緩慢放下，等待下次澆水

### 參考接線

```
Arduino A0 ← 土壤濕度感測器 AOUT
Arduino D9 → 伺服馬達信號線
5V / GND → 共用電源
```

## 技術亮點

### 1. 電容式 vs 電阻式感測器

這類專案建議使用**電容式**土壤濕度感測器而非傳統電阻式。電阻式感測器的金屬探針直接接觸濕土，長期使用會因電解腐蝕而劣化；電容式感測器表面有防護塗層，壽命更長，讀數也更穩定。

### 2. 閾值校準是關鍵

土壤濕度感測器的原始讀數會因土壤類型、感測器批次而異。正確做法是：

- 將感測器插入**完全乾燥**的土壤，記錄讀數（例如 520）
- 澆水至飽和，記錄讀數（例如 260）
- 設定閾值在兩者之間（例如 380）

不做校準就硬編閾值，是這類專案最常見的失敗原因。

### 3. 敬禮動作的細節

好的敬禮動作不是瞬間跳到目標角度，而是用 `for` 迴圈逐度遞增，搭配 `delay()` 製造流暢的揮動效果：

```cpp
// 緩慢敬禮
for (int angle = 0; angle <= 90; angle++) {
  servo.write(angle);
  delay(15);
}
// 停頓致意
delay(1000);
// 緩慢放下
for (int angle = 90; angle >= 0; angle--) {
  servo.write(angle);
  delay(15);
}
```

### 4. 防抖動設計

澆水時土壤濕度不是瞬間變化，感測器讀數會波動。加入簡單的去抖動邏輯（例如連續 5 次讀數都超過閾值才觸發），可以避免手臂反覆抽搐。

## 心得與延伸

這個專案的魅力在於它完美示範了「感測器 → 邏輯判斷 → 致動器」的基礎迴路，同時又夠荒謬有趣，讓人願意動手做。

### 延伸玩法

- **多盆聯動**：用多個感測器和馬達，讓一排盆栽像軍隊一樣依序敬禮
- **情緒系統**：加入 LED 表情——綠燈笑臉（濕潤）、紅燈哭臉（乾燥）、敬禮時閃爍
- **OLED 顯示**：加一片 0.96 吋 OLED 顯示即時濕度百分比和上次澆水時間
- **通知功能**：搭配 ESP8266/ESP32 升級版，土壤太乾時發 LINE 或 Telegram 通知
- **太陽能供電**：戶外版本搭配小型太陽能板和鋰電池，完全無線運作

### 教學價值

這是一個非常適合**親子共學**或**程式教育工作坊**的專案：
- 硬體接線只有 3 條線
- 程式碼不超過 30 行
- 成果有即時的物理回饋（手臂動了！）
- 結合自然科學（土壤、水分）和工程（感測、控制）
