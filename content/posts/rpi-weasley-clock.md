## 前言

《哈利波特》裡衛斯理家的那座魔法鐘，大概是每個麻瓜 maker 心中的白月光——九根金色指針，每一根代表一位家人，指向「家」、「上班」、「旅行」或（但願永遠不會指到的）「致命危險」。

Reddit 用戶 u/timminator93 把這個幻想變成了現實：在二手店淘到一個古董鐘殼，塞進 Raspberry Pi 3B、一顆 LD2410 毫米波人體感測器、一個繼電器和一顆 5V 電磁閥。每當家人的位置改變，電磁閥就會敲響古董鐘的銅鑼——魔法，不過是還沒被解釋的科技。

## 專案概述

### 系統架構

```
智慧手機 (OwnTracks App)
    │
    ▼ GPS 座標
Cloudflare Tunnel
    │
    ▼ 安全隧道
Raspberry Pi 3B
    ├── 位置解析引擎（多圈圍欄）
    ├── 顯示驅動（螢幕模擬鐘面）
    └── GPIO 控制
         ├── LD2410 毫米波感測器（人體存在偵測）
         └── 繼電器 → 5V 電磁閥（敲鐘）
```

### 材料清單

| 零件 | 用途 | 估價 |
|------|------|------|
| Raspberry Pi 3B | 主控 | ~$35 |
| LD2410 毫米波感測器 | 偵測是否有人在鐘前 | ~$3 |
| 5V 電磁閥 (Solenoid) | 敲擊鐘體發出聲響 | ~$5 |
| 繼電器模組 | 驅動電磁閥 | ~$2 |
| 顯示螢幕 | 模擬鐘面 UI | ~$15 |
| 古董鐘殼 | 二手店淘寶 | 隨緣 |
| **合計** | | **~$60 + 鐘殼** |

### 運作流程

1. 家人的手機透過 **OwnTracks** App 持續回報 GPS 座標
2. 資料透過 **Cloudflare Tunnel** 安全傳回家中的 RPi
3. RPi 解析座標，對照預設的地理圍欄（每個地點可設定不同半徑）
4. 螢幕上的鐘面即時更新每位家人的指針位置
5. 位置變動時，繼電器觸發電磁閥敲響古董鐘——**叮！媽媽到家了**
6. LD2410 偵測到沒人在鐘前時，螢幕自動關閉省電

## 技術亮點

### 🎯 LD2410 毫米波存在偵測

這顆不到 $3 的小模組是近年 maker 圈的明星。不同於 PIR 只能偵測「移動」，LD2410 能偵測「存在」——你坐在沙發上一動不動看書，它也知道你在。作者用它來決定螢幕是否亮起，避免 24 小時空燒顯示器。

### 🔔 電磁閥敲鐘機構

作者最初考慮用伺服馬達驅動實體指針（像其他衛斯理鐘專案那樣），但多根同軸指針的機構設計極其複雜。他選擇了螢幕顯示 + 電磁閥敲鐘的組合——視覺靠軟體，聽覺靠物理。5V 電磁閥透過繼電器由 GPIO 控制，敲擊古董鐘原本的銅鑼，聲音渾厚真實，不是喇叭能比的。

### 📱 OwnTracks + Cloudflare Tunnel

位置追蹤用的是開源的 OwnTracks，而非 Google 或 Apple 的定位服務。資料透過 Cloudflare Tunnel 回傳，不需要開放家中路由器的 port，安全性大幅提升。每個地點可以設定不同半徑的地理圍欄，精細到「在辦公室」和「在辦公室樓下便利商店」可以是不同狀態。

### ✨ 軟體鐘面的魔法細節

作者在留言中透露了幾個令人驚喜的 UI 細節：
- **外圈持續緩慢旋轉**，模擬魔法能量流動
- **星星微微閃爍**，營造魔法氛圍
- **指針有呼吸動畫**，不是死板地指著一個方向
- 螢幕尺寸、方向、對齊方式都可以在設定檔中調整
- 家庭成員增加時，只需在設定中新增一筆，不用改硬體

### 🏠 螢幕 vs 實體指針的取捨

社群中不少人（包括作者自己）最初都想做實體指針版本。但作者指出了一個關鍵問題：多根同軸指針需要精密的機械結構，而且家庭成員增加時要改硬體。螢幕方案雖然少了一些「物理感」，但換來了無限擴展性和那些微妙的動畫效果——某種意義上，這反而更接近原著中魔法鐘的神韻。

## 心得與延伸

### 為什麼這個專案特別有意思

衛斯理鐘是 RPi 社群的經典題目，但這個版本有幾個獨到之處：

1. **古董鐘殼**：不是 3D 列印外殼，是真正的老鐘。二手店淘寶的過程本身就是 maker 精神的一部分
2. **電磁閥敲鐘**：把數位事件（位置變化）轉化為物理回饋（鐘聲），這種跨界設計讓整個作品「活」了起來
3. **隱私優先**：OwnTracks + Cloudflare Tunnel，不把家人的位置資料交給大公司
4. **軟體可配置**：地點、半徑、指針樣式、顏色、螢幕關閉時間、靜音時段——全部可調

### 延伸想法

- **E-ink 圓形螢幕**：有留言建議換成 E-ink，更省電也更有「老鐘」的質感
- **Home Assistant 整合**：參考 GitHub 上的 [WeasleyClock](https://github.com/randomstring/WeasleyClock) 專案，用 HA 做位置狀態機
- **加入更多狀態**：不只是地理位置，還可以加入「開會中」、「睡覺了」等狀態（透過手機的勿擾模式或睡眠追蹤）
- **多鐘聯網**：如果家人住在不同城市，每個人家裡放一座鐘，彼此同步

### 適合誰

- 哈利波特迷（這還用說嗎）
- 想做一個「有溫度」的家庭 IoT 專案的人
- 對毫米波感測器（LD2410）有興趣的入門者
- 喜歡逛二手店、把舊東西賦予新生命的 maker
