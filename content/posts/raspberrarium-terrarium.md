## 前言

你有沒有想過，一個巴掌大的玻璃罐裡，能裝下整個晝夜輪替？

大多數「智慧植物燈」的做法是設定一個計時器：早上 6 點開、晚上 10 點關。但真實的天空不是這樣運作的——黎明有漸層、正午有暖白、黃昏有橘紅，而月亮每晚都長得不一樣。

[Raspberrarium](https://github.com/mommotti/raspberrarium) 是一個極簡但極美的開源專案：用 Raspberry Pi 搭配兩顆 WS2812 LED，在一個直徑 8 公分、高 13 公分的封閉玻璃罐裡，模擬出精確到「分鐘」的日出、正午、日落，以及跟隨真實天文資料的月相變化。每 10 秒重新計算一次色溫，96 個時間步驟構成一天的光線曲線。

不是開關燈，是一座活生生的桌上天文台。

## 專案概述

### 硬體清單

| 零件 | 說明 | 大約價格 |
|------|------|---------|
| Raspberry Pi 3B+（或任何有 GPIO 的 Pi） | 主控制器，作者原本就拿來當 NAS | ~$35（閒置的更好） |
| WS2812 LED × 2 | 左右各一顆，模擬月相盈虧 | ~$1 |
| 跳線 3 條 | 接 3.3V/5V、GND、GPIO 12 | ~$0.5 |
| 小玻璃罐 | 8cm × 13cm，任何密封容器皆可 | ~$3 |
| 半透明塑膠片 | 光線擴散片，柔化 LED 點光源 | ~$1 |
| 透氣布料 | 蓋在瓶口下方，讓濕氣緩慢排出 | ~$1 |
| 生態缸基底材料 | 碎石、樹皮、木炭、砂、泥土、培養土 | ~$5 |
| **合計** | | **~$10-15**（不含 Pi） |

如果你手邊已經有一台閒置的 Pi（誰沒有？），這個專案的額外成本幾乎為零。

### 生態缸分層結構

瓶內的分層基底由下而上：碎石 → 樹皮 → 木炭 → 砂與灰 → 泥土 → 培養土。每一層都有功能——排水、過濾、保濕、固根。作者在[搭建指南網站](https://mommotti.github.io/raspberrarium-site)裡有完整的圖文教學。

```
    │  │小世界│  │
    │  └─────┘  │
    └───────────┘
```

整個專案就一支 Python 腳本，依賴三個套件：

- **`astral`**：根據你的經緯度計算真實日出日落時間和月相
- **`adafruit-circuitpython-neopixel`**：驅動 WS2812 LED
- **`python-dotenv`**：從 `.env` 讀取時區和座標設定

啟動方式極簡：

```bash
sudo python3 raspberrarium.py --brightness 3 --silent
```

設定 `.env` 填入你的時區和經緯度，就完成了。作者也提供了 systemd service 設定，開機自動啟動、崩潰自動重啟。

## 技術亮點

### 1. 96 步平滑光線過渡

這個專案最讓人驚豔的地方，不是「能模擬日夜」，而是**怎麼模擬**。

一天被切成 96 個時間步驟（每 15 分鐘一步），系統每 10 秒重新計算一次當前的光線狀態，根據真實天文資料產生連續的色溫變化。不是「6 點開燈、18 點關燈」那種粗暴切換，而是從黎明的微光到正午的暖白、再到黃昏的橘紅，每一刻都不同。

如果你盯著看，根本察覺不到任何跳變——就像真正的天空。

### 2. 雙 LED 月相表現法

只用兩顆 LED 就能表現月相，靠的是左右亮度差異：

| 月相 | 左 LED | 右 LED |
|------|--------|--------|
| 新月 | 暗 | 暗 |
| 上弦月 | 暗 | 亮 |
| 滿月 | 亮 | 亮 |
| 下弦月 | 亮 | 暗 |

簡單到不行，但透過擴散片看起來效果出奇地好。作者還貼心提醒：如果你在南半球，把罐子轉 180 度就好。

### 3. 三段亮度與微光處理

`--brightness` 參數支援 1-3 級。作者特別註明低亮度（1-2 級）時，某些階段 LED 可能看起來像是關掉的——這不是 bug，是因為模擬的光線本來就很微弱（比如月牙階段）。這個設計選擇很有意思：寧可犧牲可見度，也要保持天文模擬的正確性。

### 4. 零維護封閉生態

瓶蓋上打了 8 個小孔：7 個用於通風和注水、1 個讓 LED 線材通過。蓋子下方鋪一層透氣布，讓濕氣能緩慢循環但不會快速蒸發。封好之後，偶爾用針筒從小孔注水就行，完全不需要打開罐子。

這是真正的「設好就忘」——Pi 跑著 systemd service 自動重啟，生態缸自己維持水循環，你唯一要做的就是偶爾欣賞它。

## 心得與延伸

### 克制的美學

這個專案的魅力在於它的**克制**。作者明確說了：這個 repo 只管光線模擬，不管植物選擇、不管環境控制。正因為範圍小，所以每個細節都打磨得很好——96 步的光線曲線、真實的天文計算、南北半球的月相修正，每一個都是「不做也沒人會抱怨」但做了就讓人會心一笑的細節。

在 Maker 圈子裡，我們太常看到「什麼都想做」的專案最後變成半成品。Raspberrarium 證明了：**做好一件小事，比做完十件大事更有價值。**

### 為什麼不用 ESP32？

作者自己也提到原本想用 ESP32。如果純粹看這個專案的需求——驅動兩顆 LED、跑一個 Python 腳本——ESP32 加 MicroPython 綽綽有餘，而且功耗低得多。但作者手邊已經有一台 Pi 3B+ 在當 NAS，多跑一個腳本根本不影響。

這是一個很實際的工程決策：**最好的平台是你已經有的那個。**

### 延伸可能

| 延伸方向 | 做法 | 難度 |
|---------|------|------|
| 換用 ESP32 | MicroPython + `astral` port，功耗降到 mA 級 | ⭐⭐ |
| 加入溫濕度感測 | BME280 + OLED 小螢幕顯示缸內環境 | ⭐ |
| 多缸同步 | 共享光線週期，或模擬不同時區（東京缸 vs 倫敦缸） | ⭐⭐ |
| 縮時攝影 | Pi Camera 每小時拍一張，記錄植物生長變化 | ⭐ |
| 雲端儀表板 | InfluxDB + Grafana 記錄光線歷史和環境數據 | ⭐⭐⭐ |
| 季節模式 | 根據日期自動調整日照時長，模擬四季變化 | ⭐⭐ |
