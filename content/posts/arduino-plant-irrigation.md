## 前言

養植物最大的敵人不是蟲害，是你忘記澆水。

一位學生為了科展，用 Arduino 做了一套自動灌溉系統。聽起來很基礎？但這個專案不只是「土壤乾了就澆水」——它還整合了加熱與冷卻系統，配上 LCD 面板即時顯示環境數據。這讓它從「入門專案」升級成了一個麻雀雖小、五臟俱全的微型智慧溫室原型。

## 專案概述

### 核心架構

整個系統圍繞 Arduino 建構，包含三大子系統：

**1. 自動灌溉**
- 土壤濕度感測器（電阻式）持續監測含水量
- 當濕度低於閾值，透過繼電器啟動水泵
- 澆水後等待滲透時間，避免過度灌溉

**2. 溫度控制**
- 加熱器：溫度低於設定值時自動啟動（保護植物免受寒害）
- 冷卻風扇：溫度過高時啟動通風散熱
- 形成一個簡單但有效的溫度閉迴路控制

**3. LCD 顯示面板**
- 即時顯示土壤濕度、環境溫度
- 澆水時顯示狀態提示
- 讓使用者不用連電腦也能掌握植物狀況

## 技術亮點

### 閉迴路溫控的巧思

大多數入門灌溉專案只管「濕度 → 水泵」這一條線。這個專案多做了溫度控制，形成了真正的環境管理系統。在程式邏輯上，它需要處理三個獨立的控制迴路：

```
土壤濕度 < 閾值 → 啟動水泵 → 等待 → 關閉
溫度 < 下限 → 啟動加熱器
溫度 > 上限 → 啟動風扇
```

這三個迴路看似簡單，但要避免衝突（例如加熱器和風扇不該同時啟動）、處理感測器噪訊、設定合理的遲滯區間（hysteresis），都是很好的工程練習。

### 從玩具到實用的距離

社群中有許多類似但更進階的版本值得參考：

- **Arduino Project Hub 的自動澆水系統**：加入超音波感測器偵測水桶水位，水泵澆完水還會播放音樂通知（是的，用 piezo buzzer 播旋律 🎵）
- **完整溫室自動化專案**：整合 BMP180 氣壓計、RTC 時鐘模組、SD 卡記錄歷史數據，可以回溯分析植物生長環境
- **IoT 升級版**：加入 ESP8266/ESP32 Wi-Fi 模組，透過 MQTT 或 Blynk 遠端監控，手機就能看到家裡植物的狀況

### 感測器選擇的學問

電阻式土壤濕度感測器（如 YL-69）便宜好用，但有個致命缺點：**電極會腐蝕**。長期使用幾週後，讀數會漂移甚至失效。進階玩家會改用電容式感測器（如 Capacitive Soil Moisture Sensor v1.2），不直接接觸水，壽命長很多。

## 心得與延伸

### 為什麼這個專案值得關注

坦白說，自動灌溉是 Arduino 世界裡的「Hello World」——幾乎每個人都做過。但正因如此，它是一個絕佳的學習載體：

1. **感測器整合**：學會讀取類比/數位感測器
2. **執行器控制**：透過繼電器驅動馬達和加熱器
3. **顯示介面**：I2C LCD 通訊協定
4. **控制邏輯**：閾值判斷、遲滯控制、時間管理

這四個技能幾乎涵蓋了所有 IoT 專案的基礎。

### 延伸方向

如果想把這個科展專案變成真正實用的系統，可以考慮：

- **加入 Wi-Fi**：ESP32 取代 Arduino，用 Home Assistant 整合
- **太陽能供電**：配合深度睡眠模式，做成戶外獨立運作的灌溉站
- **多區域管理**：用多個土壤感測器分別控制不同花盆
- **機器學習**：記錄歷史數據，讓系統學會不同植物的最佳澆水頻率
- **3D 列印外殼**：把麵包板原型變成可以長期使用的成品

### 給初學者的建議

如果你正在找第一個 Arduino 專案，自動灌溉系統真的是最好的起點之一。它有明確的目標、看得到的成果（植物活著就是成功），而且可以無限擴展。從一個感測器加一個水泵開始，慢慢加入溫控、顯示、網路連線——每一步都能學到新東西。
