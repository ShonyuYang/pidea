## 前言

養過爬蟲的人都知道，溫度和濕度是生死線。多數飼主會設定一個固定的日夜溫差循環，然後祈禱自己的守宮不會太無聊。但德國工程師 [Fraxinas] 覺得這樣不夠——他的冠紋守宮（Crested Gecko）來自南太平洋的新喀里多尼亞，那裡有熱帶雨林、有季風、有雷暴，憑什麼牠在德國只能享受恆溫 25°C？

於是他花了五年，從零開始設計了一套 ESP32 爬蟲缸自動化系統 **Geckocontroller**，不只控制溫濕度，還能根據新喀里多尼亞松島（Île des Pins）的**真實歷史氣象資料**，在缸內重現守宮老家的天氣——包括日出日落、雲層遮蔽、降雨強度，甚至閃電。

## 專案概述

### 系統架構

```
Open-Meteo API → Home Assistant → ESPHome → ESP32 控制器
                    ↓                          ↓
              歷史氣象元件              感測器 + 致動器
           (historic_weather)         (溫度/濕度/光照/雨/風)
```

整套系統分三層：

1. **氣象資料層**：自製 Home Assistant 元件 `historic_weather`，從 Open-Meteo API 抓取新喀里多尼亞的歷史天氣（因為德國在北半球，季節相反，所以用半年前的資料）
2. **中控層**：Home Assistant 負責資料記錄、視覺化、手動覆寫
3. **硬體層**：ESP32-WROOM-32E 驅動的自製 PCB，控制所有致動器

### 硬體清單

| 元件 | 型號 | 功能 |
|------|------|------|
| 主控 | ESP32-WROOM-32E-N4 | WiFi + 控制邏輯 |
| 繼電器 × 3 | TE Schrack RT444012 (DPST, 8A) | 生長燈、加熱燈、雨泵 |
| 調光器 | BT138S + FOD4208SD 光耦 | TRIAC 相位角調光 |
| RGB LED | 12V PWM 驅動 | 日出/日落/月光色彩模擬 |
| 白光 LED | MCP1416 閘極驅動 + AOD442 MOSFET | 24V 高功率植物補光 |
| 風扇 | ATX 規格 PC 風扇 | PWM + 轉速回報 + 斷電電路 |
| 溫度感測 × 2 | DS18B20 | 上下層溫度 |
| 環境感測 | BME280（天花板）+ SHT-3xD（地面） | 溫度/濕度/氣壓 |
| 體重秤 | NAU7802 + 稱重感測器 | 守宮體重追蹤 / 佔用偵測 |
| 霧化泵 | MistKing MKP-125-50 | 降雨 + 加濕噴霧 |
| 控制台 | ESP32-DevKitC + ILI9341 2.4" 觸控螢幕 | 即時天空動畫 + 操作介面 |

PCB 已經歷兩個大版本（v1.2 → v2.0），v2.0 在 2026 年 9 月完成，主要升級了繼電器（從 1A 固態改為 8A 機械式）、調光器（改用分離式 TRIAC）、以及新增白光通道。

### 氣象模擬邏輯

這是整個專案最精彩的部分。`historic_weather` 元件提供以下感測器：

- **溫度** → 恆溫器設定點（日間 26°C / 夜間 21°C 為 fallback）
- **濕度** → 恆濕器設定點（日間 65% / 夜間 80% 為 fallback）
- **天空亮度**（sky_brightness）→ 根據日照輻射與大氣頂層輻射的比值計算晴空指數，決定生長燈亮度
- **降水量**（mm/hr）→ 換算成實際噴水量（按 60×40cm 缸底面積的 15% 計算）
- **WMO 天氣代碼** → 觸發雲層飄過、閃電效果
- **風速** → 風扇 PWM 上限
- **月相** → 夜間景觀月光強度

當 Home Assistant 或氣象 API 斷線超過 10 分鐘，系統自動切換到標準日夜循環 fallback，確保守宮不會因為網路問題受苦。

### 降雨系統的精密校準

噴霧泵使用 1 公升水瓶供水，系統會追蹤每次噴水的用量：

- 校準流程：裝滿水瓶 → 啟動校準模式 → 泵連續運轉約 6 分鐘 → 量杯接水 → 輸入毫升數
- 實測流量：2.66 ml/s（通過噴嘴後，遠低於泵的開放流量）
- 每瓶可用量：970 ml
- 水位低於 10% 時自動鎖定泵浦，防止空轉

降雨強度也不是線性的——較大的降水量會產生更大的脈衝和更短的間隔，模擬真實暴雨的節奏感。

## 技術亮點

### 1. 半球偏移的巧思

德國在北半球，新喀里多尼亞在南半球。直接用即時天氣會季節相反，所以系統用 **182 天前的歷史資料**，讓缸內的夏天對應南半球的夏天。`offset_hours` 參數還能微調時區差異，讓日出日落與模擬太陽同步。

### 2. 天空亮度的物理計算

`sky_brightness` 不是簡單的「晴天 100% / 陰天 50%」，而是：

- 白天：用 **晴空指數**（clearness index = 地表輻射 ÷ 大氣頂層輻射 ÷ 晴空係數 0.75）
- 夜間：用 **雲量遮蔽係數**（滿雲 → 30% 亮度）
- 日出日落：兩者在 150 W/m² 輻射閾值處平滑混合

這意味著同樣是「多雲」，早晨和傍晚的光線效果是不同的，非常接近真實體驗。

### 3. 觸控控制台的即時天空

ESP32-DevKitC 搭配 ILI9341 觸控螢幕做成獨立控制台，首頁是一個**即時動畫天空**，跟隨模擬天氣和太陽位置變化。還有恆溫器、恆濕器、風力、燈光 HSL 色彩選擇器、守宮體重圖表等分頁。

### 4. 五年迭代的工程紀律

從 2021 年第一版原型 PCB 到 2026 年 v2.0，硬體經歷了完整的工程迭代：固態繼電器換成機械式（解決功率不足）、加入保險絲座（安全性）、HX711 換成 NAU7802（I²C 整合更乾淨）、USB 從 CP2102 換成 CH343G。這不是一次性的 weekend project，而是持續維護的生產級系統。

## 心得與延伸

這個專案讓我想到一個問題：**我們給寵物的「最佳環境」，到底是人類定義的舒適，還是牠們演化適應的自然？**

固定 25°C、65% 濕度的恆溫箱，對守宮來說可能就像人類住在永遠開著空調的購物中心——活得下去，但缺少了季節變化、天氣波動帶來的生理刺激。Fraxinas 的做法是用數據回答這個問題：與其猜測，不如直接重現原生棲息地的氣象條件。

**可能的延伸方向：**

- 🌍 **其他棲息地模板**：Open-Meteo 支援全球歷史天氣，理論上可以為任何物種的原生地建立模擬設定檔
- 📊 **行為關聯分析**：結合體重秤和攝影機，觀察守宮在不同天氣模式下的活動量、進食量變化
- 🔌 **成本估算**：整套硬體（PCB + 感測器 + 泵 + LED）大約在 €100-150 範圍，比商用爬蟲缸控制器便宜且功能強大得多
- 🐸 **水族/兩棲應用**：同樣的架構可以用於雨林蛙缸、水族箱的潮汐模擬

整個專案開源在 GitHub，包含完整的硬體設計檔、ESPHome YAML 設定、以及自製的 Home Assistant 氣象元件。對爬蟲飼主或 IoT 愛好者來說，這是一個教科書級的參考實作。
