## 前言

「如果你把一個現代人形機器人不斷刪減到最低限度，它可以多便宜？」

這是 GrowBot 專案的核心提問。答案是：一片 Raspberry Pi、兩顆伺服馬達、一顆攝影機、一個 IMU，加上幾片 3D 列印零件。材料費大約 50 美元，你就能擁有一個會走路、會看東西、還會**自己寫動作程式碼**的 AI 機器人。

Reddit 用戶 TechAirSpace 最近展示了他基於這個框架用 Pico 2 打造的版本，讓這個「最簡可行 AI 機器人」的概念再次引發討論。

## 專案概述

GrowBot 的設計哲學是「最簡可行產品」（simplest viable product）——把具身 AI（Embodied AI）從實驗室拉到你的桌上。

### 硬體清單

| 零件 | 規格 | 大約價格 |
|------|------|---------|
| 核心板 | Raspberry Pi Zero 2 W / Pico 2 | ~$10-15 |
| 伺服馬達 | 2× Feetech SCS0009 串列匯流排伺服 | ~$10 |
| 攝影機 | OV5647 或相容 CSI 攝影機模組 | ~$8 |
| IMU | MPU-6050 加速度計 + 陀螺儀 | ~$3 |
| 電池 | 3.7V LiPo + 升壓模組 | ~$8 |
| 機身 | 3D 列印（頂殼 + 底座 + 短圓腿） | ~$2 |
| **合計** | | **~$50** |

### 架構設計

```
┌─────────────────────────────────┐
│         雲端 LLM API            │
│   (GPT-4o / Claude / 免費模型)   │
└──────────┬──────────────────────┘
           │ WiFi
┌──────────▼──────────────────────┐
│     Raspberry Pi (核心控制)      │
│  ┌──────┐ ┌──────┐ ┌────────┐  │
│  │攝影機│ │麥克風│ │  IMU   │  │
│  └──┬───┘ └──┬───┘ └───┬────┘  │
│     │  感知層  │         │      │
│  ┌──▼─────────▼─────────▼──┐   │
│  │    Agent 推理引擎        │   │
│  │  - 環境理解              │   │
│  │  - 記憶系統              │   │
│  │  - 即時程式碼生成         │   │
│  └──────────┬──────────────┘   │
│             │ 動作指令          │
│  ┌──────────▼──────────────┐   │
│  │  2× SCS0009 伺服馬達     │   │
│  │  (串列匯流排控制)         │   │
│  └─────────────────────────┘   │
└─────────────────────────────────┘
```

機器人的「大腦」分兩層：本地端負責感測器讀取、馬達控制和低延遲反應；雲端 LLM 負責高階推理、環境理解和程式碼生成。兩者透過 WiFi 溝通。

## 技術亮點

### 1. 即時程式碼生成（Self-Coding）

這是整個專案最讓人興奮的部分。傳統機器人的動作是預先寫好的——走路、轉彎、停止，都是固定的函式。GrowBot 不一樣：你可以用自然語言告訴它「往前走三步然後轉圈」，LLM 會即時生成對應的伺服馬達控制程式碼，然後直接在機器人上執行。

這意味著機器人的行為集是**無限的**。它不受限於開發者預設的動作庫，而是根據指令和環境動態創造新行為。

### 2. 多模態感知 + 記憶迴路

機器人不只是執行命令。它會：
- **看**：透過攝影機捕捉環境影像，送到 LLM 做視覺理解
- **聽**：透過麥克風接收語音指令
- **記**：每次互動的結果（成功或失敗）都會被記錄下來，餵回下一次的訓練循環

這個「感知 → 推理 → 行動 → 記憶」的迴路，正是具身 AI 研究的核心架構。

### 3. 離線強化學習

除了 LLM 即時推理，GrowBot 也支援離線訓練。作者用 MuJoCo 物理引擎建了一個數位孿生（Digital Twin），在模擬環境中用強化學習訓練步態策略，再把訓練好的緊湊模型部署到實體機器人上。

### 4. 串列匯流排伺服的選擇

SCS0009 是 Feetech 的串列匯流排伺服，跟一般 PWM 伺服不同：
- 支援位置回讀（知道馬達目前角度）
- 可以串接多顆，只用一條訊號線
- 有溫度和負載回報

這讓機器人能做到閉迴路控制——知道自己的腿在哪裡，而不是盲目地送出角度指令。

## 心得與延伸

### 為什麼這個專案值得關注

具身 AI 是 2026 年最火的研究方向之一，但大多數專案的門檻都很高——動輒幾千美元的硬體、複雜的 ROS 設定、需要 GPU 的訓練環境。GrowBot 把這一切壓縮到 50 美元和一個下午的組裝時間。

它的價值不在於這個小機器人能做多厲害的事，而在於它讓你**親手體驗**「LLM + 身體」是什麼感覺。當你看到機器人根據你的一句話自己寫出動作程式碼並執行，那個「啊哈」時刻是看論文或影片無法取代的。

### 延伸可能

- **加裝更多感測器**：超音波避障、觸覺感測器、溫度感測器，讓機器人的世界模型更豐富
- **換用本地 LLM**：在 Pi 5 上跑小型語言模型（如 Phi-3-mini），實現完全離線的具身 AI
- **多機器人協作**：多台 GrowBot 透過 MQTT 溝通，探索群體智慧
- **教育應用**：這可能是最好的 AI + 機器人入門教材——便宜、直覺、開源

### 成本 vs. 學習價值

| 項目 | GrowBot | 商用教育機器人 |
|------|---------|--------------|
| 價格 | ~$50 | $200-$2000 |
| AI 整合 | ✅ LLM + RL | ❌ 通常只有預設行為 |
| 開源 | ✅ 完全開源 | ⚠️ 通常封閉 |
| 可改造性 | ✅ 3D 列印 + 開放硬體 | ❌ 固定設計 |
| 學到的東西 | 具身 AI 全棧 | 基礎程式控制 |
