## 前言

「用大蒜發電」——聽到這句話，你的第一反應大概跟 Hackaday 留言區一樣：「這是萬聖節企劃嗎？」、「是要防吸血鬼嗎？」

但這不是愚人節笑話。印度 Malaviya 國立技術學院的研究團隊真的用大蒜皮做出了一個能偵測門窗開關的自供電感測器，而且論文發表在正經的 IEEE Sensors Letters 上。更有趣的是，這東西放了半年還能用，而且材料成本趨近於零——因為原料就是你炒菜剝下來丟掉的蒜皮。

## 專案概述

### 它到底是什麼？

這是一個**摩擦奈米發電機**（Triboelectric Nanogenerator, TENG）。原理很簡單：把兩種帶不同電荷的材料疊在一起，當它們反覆接觸和分離時，就會產生交流電。你小時候用塑膠尺摩擦頭髮吸紙片，就是同一個物理現象。

### 材料清單

| 材料 | 角色 | 成本 |
|------|------|------|
| 磨碎的大蒜皮 | 正電荷層 | ≈ 免費（廚餘） |
| 聚乙烯薄膜（PE） | 負電荷層 | ≈ 塑膠袋等級 |
| 銅箔電極 | 集電層 | 極低 |
| MCU + 藍牙模組 | 訊號處理與傳輸 | 依選型而定 |

### 關鍵數據

- **單層蒜皮**：開門產生約 **210 VAC**，短路電流 **45 µA**
- **雙面蒜皮層**：提升至 **400 VAC**，**65 µA**
- **耐久性**：儲放 **6 個月**後仍可運作，通過 **200 次**應力循環測試

是的，你沒看錯——400 伏特。但別擔心，電流只有微安等級（65 µA），功率大約只有 26 毫瓦。這不會電死你，但足以驅動一個超低功耗的無線訊號。

## 技術亮點

### 為什麼偏偏是大蒜皮？

研究者 Deepak Bharti 解釋，大蒜皮有三個天然優勢：

1. **表面紋理**：蒜皮天然具有多層、粗糙的微結構，這對接觸起電（contact electrification）非常有利——表面積越大，電荷轉移越多
2. **全球大量廢棄**：大蒜是全球產量最大的辛香料之一，蒜皮幾乎 100% 被丟棄
3. **可生物降解**：不像合成聚合物，蒜皮最終會自然分解

團隊之前也試過花生殼和甘蔗渣，但蒜皮的性能最好。

### TENG 的工作原理

```
┌─────────────────────────┐
│     銅箔電極 (上)        │
├─────────────────────────┤
│   磨碎大蒜皮 (+)        │  ← 正電荷材料
├─────────────────────────┤
│                         │  ← 接觸/分離界面
├─────────────────────────┤
│   聚乙烯薄膜 (-)        │  ← 負電荷材料
├─────────────────────────┤
│     銅箔電極 (下)        │
└─────────────────────────┘

門開 → 兩層分離 → 電荷重新分佈 → 產生交流電壓脈衝
門關 → 兩層接觸 → 電荷中和 → 電壓歸零
```

安裝在門框上時，每次開關門都會讓兩層材料接觸和分離，產生一個可偵測的電壓脈衝。這個脈衝本身就是「門被打開了」的訊號——不需要額外的電池來供電給感測器本身。

### 目前的限制

論文中的示範系統用了一個 MCU 搭配行動電源來處理訊號並透過藍牙傳送，這顯然沒有真正解決「電池沒電」的問題。但 Hackaday 的評論者也指出，理論上 TENG 產生的能量足以直接驅動一個超低功耗的無線封包（例如 BLE beacon），完全不需要外部電源。

## 心得與延伸

### 這真的實用嗎？

老實說，目前還不太實用。26 毫瓦的瞬時功率聽起來不少，但只在開門的瞬間產生，你需要一個能量儲存電路（超級電容或薄膜電池）來累積能量，再在需要時釋放。而且蒜皮的長期穩定性（超過半年呢？一年呢？）還需要更多驗證。

### 但它為什麼重要？

這個專案的價值不在於「用大蒜取代鋰電池」，而在於它展示了一個思路：

1. **廢料即材料**：全球每年產生數百萬噸的農業廢棄物，如果其中一小部分能變成功能性材料，影響是巨大的
2. **自供電 IoT 的可能性**：在不方便換電池的場景（偏遠地區、大量部署的感測器網路），TENG 技術可能是解方
3. **DIY 友善**：不需要半導體製程，不需要稀土材料，理論上你在家就能做

### 延伸玩法

如果你想自己試試 TENG：

- **材料替換實驗**：試試洋蔥皮、玉米葉、茶葉渣——哪種廚餘發電效率最高？
- **搭配 ESP32 深度睡眠**：用超級電容儲能 + ESP32 的 deep sleep 模式，實現真正的零電池門窗感測器
- **結合 Zigbee/Matter**：比 BLE 更適合智慧家庭整合的通訊協定

材料費大概就是一顆大蒜 + 一個塑膠袋的錢。最貴的部分反而是你的好奇心。
