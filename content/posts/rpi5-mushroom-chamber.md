你知道種蘑菇比養多肉還挑剔嗎？

秀珍菇出菇要 10–21°C、濕度 85–95%、CO₂ 低於 800 ppm；猴頭菇更嚴格，18–24°C 且濕度必須 90% 以上，否則長出來的不是漂亮的獅子鬃毛，而是一團珊瑚狀的失敗品。人類的體感根本無法精確控制這些參數——但 Raspberry Pi 可以。

一位軟體開發科系的學生決定把程式設計課學到的東西用在真實世界：他在衣櫃裡用 RPi 5 加上 4 通道繼電器模組，打造了一座全自動菇類種植箱。整個專案已開源。

## 專案概述

### 核心架構

```
BME280 感測器 → RPi 5 → 4 通道繼電器 → 執行器
  (溫/濕/氣壓)     (Python)    (GPIO)      ↓
                                    ┌──────────────┐
                                    │ 超音波加濕器  │
                                    │ PTC 加熱墊    │
                                    │ 排氣風扇      │
                                    │ LED 光照      │
                                    └──────────────┘
```

**硬體清單：**

| 元件 | 型號 | 用途 | 參考價格 |
|------|------|------|----------|
| 主控 | Raspberry Pi 5 (4GB) | 讀取感測器、控制邏輯、Web UI | ~$60 |
| 感測器 | BME280 (I²C) | 溫度 ±1°C / 濕度 ±3% / 氣壓 | ~$5 |
| 繼電器 | 4 通道 5V 繼電器模組 | 切換 AC 設備 | ~$4 |
| 加濕器 | 超音波霧化器 | 維持 85–95% RH | ~$15 |
| 加熱 | PTC 加熱墊 12V | 冬季升溫 | ~$8 |
| 風扇 | 12V DC 風扇 | CO₂ 排氣 + 降溫 | ~$5 |
| 光照 | LED 燈條（可選） | 模擬光週期 | ~$5 |
| **合計** | | | **~$102** |

加上衣櫃或收納箱本身，總成本約 $120 以內——比市售智慧種植箱便宜 5 倍以上。

## 技術亮點

### 1. BME280：一顆感測器搞定三件事

BME280 透過 I²C 匯流排同時提供溫度、相對濕度和氣壓讀數。在 Python 中只需幾行：

```python
import smbus2
import bme280

port = 1
address = 0x76
bus = smbus2.SMBus(port)
calibration = bme280.load_calibration_params(bus, address)

data = bme280.sample(bus, address, calibration)
print(f"溫度: {data.temperature:.1f}°C")
print(f"濕度: {data.humidity:.1f}%")
print(f"氣壓: {data.pressure:.1f} hPa")
```

為什麼不用 DHT22？BME280 精度更高（±1°C vs ±0.5°C）、支援 I²C 不佔 GPIO、而且多了氣壓讀數——氣壓突變通常代表通風口被堵住或箱體密封出問題。

### 2. 繼電器控制邏輯：不只是開關

4 通道繼電器的每一路對應一個執行器，但控制邏輯不能只是「超過閾值就開」。蘑菇對環境變化敏感，頻繁開關加濕器會造成溫度震盪。這個專案的做法是加入**遲滯區間（hysteresis）**：

```
目標濕度: 90%
開啟加濕器: < 87%  (低於目標 3%)
關閉加濕器: > 93%  (高於目標 3%)
```

這個 ±3% 的死區避免了繼電器在閾值附近反覆切換（chattering），延長設備壽命也讓環境更穩定。

### 3. 為什麼蘑菇需要這麼精確的控制？

不同菇種的環境需求差異驚人：

| 菇種 | 出菇溫度 | 濕度 | CO₂ 上限 | 特殊需求 |
|------|---------|------|---------|---------|
| 秀珍菇 | 10–21°C | 85–95% | <800 ppm | 高換氣量 |
| 猴頭菇 | 18–24°C | 90–95% | <800 ppm | CO₂ 過高會變珊瑚狀 |
| 香菇 | 10–21°C | 80–90% | <1000 ppm | 需要褐化期 35–70 天 |
| 杏鮑菇 | 15–18°C | 85–90% | 500–800 ppm | 溫度範圍最窄 |
| 靈芝 | 24–29°C | 90–95% | 依形態而定 | 高 CO₂ 長鹿角、低 CO₂ 長扇形 |

靈芝的案例特別有趣：同一個菌種，光靠調整 CO₂ 濃度就能決定它長成鹿角狀還是扇形——這就是精密環境控制的威力。

### 4. Web UI 即時監控

專案用 Flask 建立了一個輕量級 Web 介面，讓你用手機就能：

- 📊 即時查看溫度、濕度、氣壓曲線
- 🎯 設定各菇種的目標參數
- 🔄 手動覆蓋繼電器狀態（緊急降溫等）
- 📈 查看歷史趨勢圖

Flask 跑在 RPi 5 上幾乎不佔資源，而且不需要任何雲端服務——你的種植數據完全留在本地。

## 類似專案比較

這不是第一個用 RPi 種蘑菇的專案，但各有側重：

| 專案 | 主控 | 感測器 | 特色 |
|------|------|--------|------|
| **本專案** | RPi 5 | BME280 | 最簡潔、開源、Flask UI |
| AgroPi | RPi 4 | SHT31D + VEML7700 + SGP30 | 多感測器、含攝影機、Nginx 前端 |
| MycoClimate | Arduino 系 | 溫濕度 + CO₂ | 3D 列印外殼、內建螢幕 UI |
| Zigbee 方案 | RPi + CC2531 | Zigbee 無線感測器 | 無線架構、Home Assistant 整合 |

本專案的優勢在於**入門門檻最低**：一塊 RPi 5、一顆 BME280、一個繼電器模組，加上一個衣櫃，就能開始。不需要 3D 列印機，不需要焊接 PCB，不需要設定 Zigbee 網路。

## 心得與延伸

### 這個架構還能種什麼？

同樣的「感測器 → 主控 → 繼電器 → 執行器」架構，換掉目標參數就能用在：

- 🌱 **育苗箱** — 控制光照時數和土壤濕度
- 🦎 **爬蟲箱** — 日夜溫差模擬 + UVB 燈控制
- 🍷 **酒窖** — 恆溫恆濕長期監控
- 🧀 **起司熟成箱** — 溫度 10–13°C、濕度 80–85%

### 進階升級路線

如果想更進一步：

1. **加裝 SCD40 CO₂ 感測器** — BME280 沒有 CO₂ 讀數，但 CO₂ 是蘑菇形態的關鍵因子
2. **接攝影機做縮時攝影** — 記錄從菌絲到出菇的全過程
3. **整合 Home Assistant** — 用 MQTT 把數據推到 HA 儀表板
4. **加裝 PID 控制** — 從簡單的遲滯控制升級到 PID，溫度波動可以壓到 ±0.5°C 以內
5. **多箱管理** — 一台 RPi 5 的算力足以同時控制 3–4 個種植箱

### 最大的學習價值

這個專案看似在種蘑菇，其實是一個完整的 IoT 控制系統教學：感測器讀取、GPIO 控制、閉環回饋、Web 前端、資料視覺化。學完這些，你離做一台自動化溫室或智慧家居中控也不遠了。

而且最後你還能吃到自己種的猴頭菇——這大概是所有 Maker 專案中 ROI 最高的一個。
